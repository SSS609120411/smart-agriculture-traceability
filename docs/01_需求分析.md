# 智慧农产品溯源管理系统 — 需求分析

## 1. 项目背景

随着人民生活水平提高，消费者对农产品的质量安全日益关注。传统农产品流通环节信息不透明，消费者难以了解所购农产品的生产来源、质量检测、加工与物流过程。食品质量安全事件的频发，使得「来源可查、去向可追、责任可究」的农产品溯源需求愈发迫切。

智慧农产品溯源管理系统通过信息化手段，将农产品从**生产（种植）→ 质检 → 加工 → 物流 → 销售**的全过程关键信息记录下来，并为每个生产批次生成**唯一溯源码与二维码**。消费者扫描二维码即可查看该产品的完整溯源链条，实现「从农田到餐桌」的透明化管理，提升消费者信任度，助力农业数字化转型。

## 2. 项目目标

1. 构建一套 B/S 架构的农产品溯源管理应用软件；
2. 实现农产品分类、产品、批次的信息化管理；
3. 实现生产、质检、加工、物流、销售五个环节的记录与查询；
4. 为每个批次生成唯一溯源码与二维码，支持消费者扫码溯源；
5. 提供数据看板，直观展示整体运营情况；
6. 基于角色实现权限隔离（管理员 / 生产者 / 消费者）。

## 3. 用户角色

| 角色 | 说明 | 主要职责 |
|------|------|----------|
| 管理员（admin） | 系统管理员 | 管理用户、产品分类，查看全局数据，具备全部数据维护权限 |
| 生产者（producer） | 农户 / 生产企业 | 维护产品，创建批次，录入种植、质检、加工、物流、销售各环节记录 |
| 消费者（consumer） | 终端用户 / 游客 | 通过溯源码或二维码查询产品溯源信息 |

> 溯源查询接口对游客开放（无需登录），保障普通消费者的使用便利性。

## 4. 功能需求

### 4.1 认证与权限

| 编号 | 功能 | 描述 |
|------|------|------|
| FR-01 | 登录 | 用户凭用户名 + 密码登录，返回 JWT 令牌 |
| FR-02 | 注册 | 消费者自助注册；生产者/管理员由管理员创建 |
| FR-03 | 权限控制 | 接口级角色校验，越权访问返回 403 |

### 4.2 基础数据管理

| 编号 | 功能 | 描述 | 权限 |
|------|------|------|------|
| FR-04 | 产品分类管理 | 分类的新增、编辑、删除、查询 | 管理员 |
| FR-05 | 产品管理 | 产品（名称、产地、品种、描述）的增删改查，按分类筛选 | 管理员/生产者 |

### 4.3 批次与溯源核心

| 编号 | 功能 | 描述 | 权限 |
|------|------|------|------|
| FR-06 | 批次创建 | 选择产品创建批次，自动生成唯一溯源码与二维码 | 管理员/生产者 |
| FR-07 | 批次管理 | 批次列表、详情、编辑、删除 | 管理员/生产者 |
| FR-08 | 二维码 | 查看、下载批次溯源二维码 | 登录用户 |

### 4.4 环节记录

| 编号 | 功能 | 描述 | 权限 |
|------|------|------|------|
| FR-09 | 种植记录 | 播种/施肥/用药/灌溉/采摘等农事操作记录 | 管理员/生产者 |
| FR-10 | 质检记录 | 检测日期、检测人、检测项目、结果、报告 | 管理员/生产者 |
| FR-11 | 加工记录 | 加工日期、类型、详情、操作人 | 管理员/生产者 |
| FR-12 | 物流记录 | 起运地、目的地、承运方、温度等 | 管理员/生产者 |
| FR-13 | 销售记录 | 销售渠道、数量、价格、买方 | 管理员/生产者 |

### 4.5 溯源查询与统计

| 编号 | 功能 | 描述 | 权限 |
|------|------|------|------|
| FR-14 | 溯源查询 | 输入溯源码，返回产品信息 + 全链路时间轴 | 公开 |
| FR-15 | 数据看板 | 产品/批次/分类/用户统计、分类分布、状态分布、环节统计 | 登录用户 |
| FR-16 | 用户管理 | 用户的增删改查、角色分配、重置密码 | 管理员 |

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 常规 CRUD 接口响应时间 < 1s；支持常见并发访问 |
| 安全性 | 密码加密存储（哈希）；JWT 令牌鉴权；接口级角色校验；防越权 |
| 易用性 | 界面简洁直观，基于 Element Plus 组件库，中文界面 |
| 可维护性 | 前后端分离，后端按模块划分路由，代码结构清晰 |
| 可移植性 | 数据库引擎可配置（MySQL 为主，兼容 SQLite） |
| 兼容性 | 支持主流浏览器（Chrome / Edge / Firefox） |
