# 智慧农产品溯源管理系统 — 数据库设计

## 1. 数据库概述

- 数据库名：`traceability`
- 字符集：`utf8mb4`
- 引擎：`InnoDB`
- 共 **10 张表**，核心为 `batches`（批次）与 5 张环节记录表。

## 2. ER 关系

```
users (用户)
  │ 1
  │
  │ N
batches (批次) ──N:1── products (产品) ──N:1── categories (分类)
  │ 1
  │ N
  ├── planting_records      (种植记录)
  ├── quality_inspections   (质检记录)
  ├── processing_records    (加工记录)
  ├── logistics_records     (物流记录)
  ├── sales_records         (销售记录)
  └── trace_logs            (查询日志)
```

- 一个分类下有多个产品，一个产品可有多个批次；
- 一个批次由一个生产者创建，包含多条各环节记录；
- 各环节记录、查询日志通过 `batch_id` 外键关联批次，删除批次时级联删除（`ON DELETE CASCADE`）。

## 3. 表结构

### 3.1 users（用户表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | 主键，自增 | 用户编号 |
| username | VARCHAR(64) | 唯一，非空 | 用户名 |
| password_hash | VARCHAR(256) | 非空 | 密码哈希 |
| role | VARCHAR(20) | 非空 | 角色：admin/producer/consumer |
| name | VARCHAR(64) | | 姓名 |
| phone | VARCHAR(20) | | 手机号 |
| created_at | DATETIME | | 创建时间 |

### 3.2 categories（产品分类表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | 主键，自增 | 分类编号 |
| name | VARCHAR(64) | 唯一，非空 | 分类名称 |
| description | VARCHAR(256) | | 描述 |

### 3.3 products（产品表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | 主键，自增 | 产品编号 |
| category_id | INT | 外键→categories.id，非空 | 所属分类 |
| name | VARCHAR(128) | 非空 | 产品名称 |
| origin | VARCHAR(128) | | 产地 |
| variety | VARCHAR(128) | | 品种 |
| description | VARCHAR(512) | | 描述 |
| image_url | VARCHAR(256) | | 图片地址 |
| created_at | DATETIME | | 创建时间 |

### 3.4 batches（批次表 · 核心溯源单元）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INT | 主键，自增 | 批次编号 |
| product_id | INT | 外键→products.id，非空 | 所属产品 |
| producer_id | INT | 外键→users.id，非空 | 生产者 |
| trace_code | VARCHAR(64) | 唯一，非空 | 溯源码 |
| qr_code | VARCHAR(256) | | 二维码图片路径 |
| production_date | VARCHAR(20) | | 生产日期 |
| quantity | VARCHAR(64) | | 数量 |
| unit | VARCHAR(20) | | 单位 |
| status | VARCHAR(20) | | 状态：生产中/加工中/已上市 |
| created_at | DATETIME | | 创建时间 |

| id | INT | 主键，自增 | 编号 |

| record_type | VARCHAR(32) | | 类型：播种/施肥/用药/灌溉/采摘 |
| detail | VARCHAR(512) | | 详情 |
| record_date | VARCHAR(20) | | 记录日期 |
| location | VARCHAR(128) | | 位置 |

| inspector | VARCHAR(64) | | 检测人 |
| items | VARCHAR(256) | | 检测项目 |

| 字段 | 类型 | 约束 | 说明 |

| id | INT | 主键，自增 | 编号 |
| batch_id | INT | 外键→batches.id，非空 | 所属批次 |

| batch_id | INT | 外键→batches.id，非空 | 所属批次 |
