# 智慧农产品溯源管理系统 — 用户手册

## 1. 登录与注册

1. 打开系统，进入登录页。
2. 输入用户名和密码，点击「登录」。
3. 首次使用的消费者可点击「注册账号」自助注册（注册后默认为消费者角色）。
4. 无需登录也可点击「游客溯源查询」直接进入溯源查询页。

> 演示账号：管理员 `admin/admin123`，生产者 `producer/producer123`，消费者 `consumer/consumer123`。

## 2. 管理员操作

登录管理员账号后，左侧菜单包含：数据看板、产品分类、产品管理、批次管理、用户管理。

### 2.1 产品分类管理

- 点击「产品分类」→「新增分类」，填写名称与描述后保存；
- 点「编辑」修改，点「删除」移除（分类下有产品时不允许删除）。

### 2.2 产品管理

- 点击「产品管理」→「新增产品」，选择分类、填写名称/产地/品种/描述；
- 支持按分类筛选。

### 2.3 用户管理

- 点击「用户管理」→「新增用户」，填写用户名、姓名、手机号，选择角色（管理员/生产者/消费者），设置初始密码；
- 编辑用户时可重置密码（留空则不修改）。

## 3. 生产者操作

登录生产者账号后，可维护产品、批次与各环节记录。

### 3.1 创建批次

1. 进入「批次管理」→「新建批次」。
2. 选择产品，填写生产日期、数量、单位、状态，点击「创建」。
3. 系统自动生成唯一**溯源码**与**二维码**。

### 3.2 录入环节记录

1. 在「批次管理」列表点击某批次的「详情」。
2. 切换到「种植 / 质检 / 加工 / 物流 / 销售」任一 Tab，点击「新增 XX 记录」。
3. 填写对应信息后保存；点「删除」可移除记录。

### 3.3 查看与下载二维码

- 在「批次管理」列表点击「二维码」，可查看并「下载二维码」图片。

## 4. 消费者溯源查询

1. 打开溯源查询页（登录页「游客溯源查询」，或扫码进入）。
2. 输入溯源码（或直接扫描商品二维码自动跳转）。
3. 页面展示：产品名称、分类、产地、品种、生产日期、生产单位，以及按时间排列的完整溯源链条（种植 → 质检 → 加工 → 物流 → 销售）。

## 5. 数据看板

登录任意账号后，首页「数据看板」展示：产品/批次/分类/用户数量统计卡片，以及「产品分类分布」「批次状态分布」「各环节记录统计」三个图表。
