# 智慧农产品溯源管理系统 — 在线部署指南

## 部署架构

```
GitHub 仓库（代码托管）
   ├── GitHub Pages  →  前端静态页面（Vue 构建产物）
   └── PythonAnywhere →  Flask 后端 + MySQL 数据库
```

最终访问地址：

- 前端：`https://你的用户名.github.io/仓库名/`
- 后端：`https://你的用户名.pythonanywhere.com`

> 前端通过 `VITE_SERVER_BASE` 指向后端地址；后端已开启 CORS，允许跨域访问。

---

## 第一步：把代码推送到 GitHub

### 1.1 安装 Git 并配置身份

```powershell
winget install --id Git.Git -e
# 安装后重新打开终端
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

### 1.2 在本地初始化仓库并提交

```powershell
cd "G:\软件工程实践\智慧农产品溯源管理系统"
git init -b main
git add .
git commit -m "feat: 智慧农产品溯源管理系统"
```

> `.gitignore` 已配置，`.env`、`node_modules`、`__pycache__` 等不会上传。

### 1.3 在 GitHub 创建空仓库并推送

1. 打开 <https://github.com/new>，仓库名建议 `smart-agriculture-traceability`；
2. **不要**勾选 README / .gitignore / License（保持空仓库）；
3. 按页面提示执行：

```powershell
git remote add origin https://github.com/你的用户名/smart-agriculture-traceability.git
git push -u origin main
```

第一次推送会弹出浏览器登录 GitHub，授权即可。

## 第二步：部署后端到 PythonAnywhere

### 2.1 注册并拉取代码

1. 注册 <https://www.pythonanywhere.com>（免费账号即可）；
2. 打开 **Consoles → Bash**，执行：

```bash
git clone https://github.com/你的用户名/smart-agriculture-traceability.git
cd smart-agriculture-traceability
```

### 2.2 创建虚拟环境并安装依赖

```bash
mkvirtualenv --python=/usr/bin/python3.10 trace-venv
pip install -r ~/smart-agriculture-traceability/backend/requirements.txt
```

> 以后重新进入虚拟环境用 `workon trace-venv`。

### 2.3 创建 MySQL 数据库

1. 顶部菜单 **Databases → Create a database**，名称填 `traceability`；
2. 系统会生成实际库名：`你的用户名$traceability`，并让你设置数据库密码，**记下来**。

### 2.4 建表

1. 点击刚创建的数据库进入 **MySQL console**；
2. 先执行：

```sql
USE 你的用户名$traceability;
```

3. 打开本地 `deploy/pa_init.sql`，把内容复制粘贴执行。

### 2.5 配置环境变量

在 Bash 控制台执行（把中文占位替换成实际值）：

```bash
nano ~/smart-agriculture-traceability/backend/.env
```

粘贴以下内容，`Ctrl+O` 保存、`Ctrl+X` 退出：

```ini
MYSQL_HOST=你的用户名.mysql.pythonanywhere-services.com
MYSQL_PORT=3306
MYSQL_USER=你的用户名
MYSQL_PASSWORD=数据库密码
MYSQL_DB=你的用户名$traceability
SECRET_KEY=换成一串随机字符
TRACE_PAGE_PREFIX=https://你的用户名.github.io/smart-agriculture-traceability/#/trace/
```

> `TRACE_PAGE_PREFIX` 是二维码指向的前端地址，**必须先确定**，之后生成的二维码才正确。

### 2.6 初始化种子数据

```bash
workon trace-venv
cd ~/smart-agriculture-traceability/backend
python seed.py
```

成功后会打印演示账号和一个示例溯源码。

### 2.7 创建 Web 应用

1. 顶部菜单 **Web → Add a new web app**；
2. 选择 **Manual configuration → Python 3.10**；
3. 在配置页设置：
   - **Source code**：`/home/你的用户名/smart-agriculture-traceability/backend`
   - **Virtualenv**：`/home/你的用户名/.virtualenvs/trace-venv`
4. 点击 **WSGI configuration file** 链接，用 `deploy/pythonanywhere_wsgi.py` 的内容整体替换（记得改里面的用户名和仓库名）；
5. 点击页面上方 **Reload**。

验证：浏览器访问 `https://你的用户名.pythonanywhere.com/api/health`，返回 `{"code":0,"message":"ok"}` 即成功。

## 第三步：部署前端到 GitHub Pages

### 3.1 开启 Pages

仓库页面 → **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

### 3.2 配置后端地址变量

仓库页面 → **Settings → Secrets and variables → Actions → Variables → New repository variable**：

| Name | Value |
|------|-------|
| `VITE_SERVER_BASE` | `https://你的用户名.pythonanywhere.com` |

### 3.3 触发构建

向 `main` 分支推送任意提交（修改 `frontend/` 下文件会自动触发），或到 **Actions** 页手动运行 `Deploy Frontend to GitHub Pages`。

构建完成后访问：

```
https://你的用户名.github.io/smart-agriculture-traceability/
```

## 常见问题

| 问题 | 原因与解决 |
|------|------------|
| 后端 502 / 500 | 查看 PythonAnywhere **Web → Error log**；多为 `.env` 配置或依赖未装 |
| 前端请求 401/网络错误 | 检查 `VITE_SERVER_BASE` 是否正确，修改后需重新触发 Actions 构建 |
| 二维码图片不显示 | 确认 `VITE_SERVER_BASE` 已配置（图片地址指向后端域名） |
| 扫码打开旧地址 | `TRACE_PAGE_PREFIX` 设置后需重新运行 `seed.py` 或重建批次 |
| 免费账号访问慢 | PythonAnywhere 免费应用会休眠，首次访问需等待几十秒 |
| 数据库连不上 | 免费 MySQL 主机名是 `用户名.mysql.pythonanywhere-services.com`，不是 localhost |

## 安全提示

- 本系统为课程演示项目，**上线后请修改默认密码**；
- 不要把 `.env`、数据库密码、`SECRET_KEY` 提交到 GitHub；
- 仓库设为 Public 才能免费使用 GitHub Pages（私有仓库需 GitHub Pro）。
